# Seed knowledge documents

These are **synthetic demo documents** written for the Site Guard AI pilot. They imitate the shape of a
contractor's site procedures and inspection test plans (ITPs) so retrieval, compliance mapping and CAPA can be
demonstrated end to end. They are **not** regulations and must not be relied on for real work.

`regulatory-pointers.md` lists real public regulations by name and section number only, as pointers for
customers to load their own licensed or official copies. Verify every pointer against the current official text.

Front matter fields are read by `backend/app/seed.py`.
